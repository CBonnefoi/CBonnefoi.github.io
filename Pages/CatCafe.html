Kitt'n Coffee

5 Month-long, published cat café idle game

The project
Kitt'n Coffee is an idle game in which the player manages his own cat café. The player can discover up to 15 cats, 5 recipes as well as customizing the furniture of his café !
My main roles during this project were :

  • Balancing : Developing balancing tools and workflows and applying them to try and make the user experience more fun and engaging, while maintaining a sufficient playtime and a rewarding progression
  • Producing : Setting deadlines, making sure they are respected and assigning tasks
  • Game Design : Creating and iterating on the base concept and mechanics, depending on the target audience and several rounds of feedback
  • QA Testing : Organizing targeted playtest sessions and formalizing the feedback, then coordinating the programmers and artists to fix reported issues

My role in Balancing
As I was responsible for balancing the game, I was responsible for setting up tools, discussing with the Game Programmers to see which tools they could create, and finally, setting the values of every element and testing it.

Most of the balancing would initially be done using .CSV files, allowing for total control over the game's values. This was only possible thanks to an import tool the Game Programmers made for me, and the export tool I made for Google Sheets.

The second tool our Game Programmers made us was a tool logging every action in a game, and exporting it in .CSV format.
This allowed us to look deeper into what really was happening, as well as taking our time to analyze the player's actions.

Since this data is quite unreadable, I had to use Google Sheets to create tools allowing us to see all of that data in a more readable way.
